# Зміни цін

Кожен JSON-файл тут — пакет змін прайсу. Після деплою сервер при старті застосовує
нові файли по черзі (за назвою) і записує їх у колекцію `priceChanges` разом зі
значеннями «до» і «після». Уже застосований файл повторно не виконується, тому
ручні правки в адмінці він не перезапише.

Назва файлу: `РРРР-ММ-ДД-короткий-опис.json`. Застосовані файли не редагуйте —
для нових змін створюйте новий файл.

Перед деплоєм перевірте, що саме зміниться на сайті:

```
cd server && npm run price-changes:check
```

## Формат

```json
{
  "description": "Що і навіщо змінюємо",
  "changes": [
    { "category": "Хімчистка", "title": "Піджак", "standard": 457, "premium": 687 },
    { "category": "Чистка домашнього текстилю", "title": "Наволочка", "standard": null, "premium": 117 },
    { "category": "Хімчистка", "title": "Пальто", "newTitle": "Пальто демісезонне" },
    { "action": "delete", "category": "Хімчистка", "title": "Стара позиція" }
  ]
}
```

- `category`, `title` — назви як на сайті (регістр і зайві пробіли не важливі).
- Дія за замовчуванням `set`: якщо позиція є — змінюються лише вказані поля,
  якщо немає — створюється в кінці категорії.
- `standard` / `premium` — число (грн), текст (напр. `"від 300"`) або `null` = порожньо.
- Необов'язкові: `quantity` (за замовчуванням `"шт"`), `discountPercent` (0, 10, 15, 20, 30),
  `newTitle` — перейменувати.
- `"action": "delete"` — видалити позицію.
